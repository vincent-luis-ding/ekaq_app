# EKAQ Android App

一个简单的 WebView 壳 App，全屏加载 https://ekaq.com。

## 使用方法

1. 在 GitHub 新建一个仓库（比如 `ekaq-android`）
2. 把这个项目的所有文件推上去
3. GitHub Actions 会自动编译，编译完成后在仓库的 **Actions** 页面可以下载 APK
4. 下载 `app-debug.apk` 安装到手机即可

## 效果

- 打开 App 直接全屏显示 ekaq.com 网页
- 无浏览器地址栏、无菜单
- 状态栏深色 (#0B111E)，和网站融为一体
- 支持返回键（网页内后退）
